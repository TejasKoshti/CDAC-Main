Create a page with a navbar that includes links to Home, About, Signup, and Login. The Signup page should feature a form with fields for username, email, and password. Upon submission, the user will be redirected to the Login page.

Login page: The user will enter their username and password. Upon submission, the system will verify if the username is valid. If valid, the user will be redirected to the Home page, where their username will appear in the header. Initially, the header will display a default menu (Home, About, Blog, Contact Us). After login, the header will update to show a Logout button on the right side and the logo on the left side.
